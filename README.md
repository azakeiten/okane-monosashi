# おかねの物差し

**その値段、あなたの何時間ぶん？**

ニュースに出てくるお金の大きな数字を、「はたらく時間」「おこづかい」「昔の値段」など、自分の生活の単位に直して見せるサイトです。小学生から大人まで、授業や自由研究にも使えます。

👉 **サイトを開く：https://azakeiten.github.io/okane-monosashi/**

👩‍🏫 **先生・おうちの人へ（授業プラン5つ）：https://azakeiten.github.io/okane-monosashi/guide.html**

## できること

| パート | 中身 |
| --- | --- |
| ホーム | 値段を入れると、はたらく時間・おこづかい何か月・おにぎり何個に換算。都道府県と生まれた年で作る「あなたの物差しカード」。目的べつの「おすすめコース」4つ |
| PART 1 くらべる | お金の3つの役割と硬貨のひみつ、36品目の「何時間はたらく？」、47都道府県の地図（くらしの物価の高さ・物価を考えた時給も）、10年間の値上がりランキング |
| PART 2 さかのぼる | 1970年までさかのぼる物価タイムマシン、給料と物価、貯金とインフレ（ほしい物までの貯金計画つき）、1ドルは何円？（円安・円高） |
| PART 3 しくみ | 家族の1か月の支出を1万円にちぢめた100マス、学校にかかるお金、初任給の給与明細、年れいごとの給料、国の予算や借金を1人あたりに、消費税のレシート、わたしのおこづかい帳 |
| PART 4 たしかめる | 5つのモードのお金クイズ、ことば辞典、印刷できる自由研究ワークシート、スタンプラリー |

## 使っているデータ

数字はすべて、国や公的機関が公表している統計です。

- 総務省統計局「2025年基準消費者物価指数 長期時系列データ」（1970〜2025年）
- 総務省統計局「小売物価統計調査（動向編）」（東京都区部・県庁所在市の年平均価格）
- 総務省統計局「小売物価統計調査（構造編）消費者物価地域差指数」（2025年）
- 文部科学省「令和5年度 子供の学習費調査」（令和8年1月の訂正後）
- 総務省統計局「家計調査 長期時系列表」（2人以上の世帯、2000〜2025年）
- 厚生労働省「地域別最低賃金」（2002〜2026年度）
- 厚生労働省「令和7年賃金構造基本統計調査」（初任給・年れいごとの所定内給与額）
- 日本銀行「東京市場 ドル・円 スポット 17時時点 月中平均」（1990〜2026年）
- 財務省（令和8年度予算・普通国債残高の見込み）、内閣府（2025年の名目GDP速報値）、財務省（令和8年度の税収予算）、総務省統計局「人口推計」
- 財務省「通常貨幣一覧」（硬貨の直径・重さ）
- 全国健康保険協会・日本年金機構・こども家庭庁・厚生労働省（2026年度の保険料率）

計算はすべて「目安」です。平均の数字を使っているため、一人ひとりの値段や給料とはちがいます。

## 更新のルール

年に1回、前の年の物価指数と品目の値段が出る春と、最低賃金が決まる秋に見直します。サイトの「データの出どころ」の章に、それぞれの数字の時期と次の更新の目安を表で出しています（`okane-data.js` の `DATA_FRESH`）。

### 更新の手順（どの数字を、どこから取って、どこを直すか）

数字はすべて `okane-data.js` にまとまっています。直したら `bash dev/build.sh` で `index.html` を作り直し、GitHubにアップロードします。最後に、`dev/okane-monosashi.html` のいちばん下の「最終更新」の日付を変えます。

| いつ | データ | 取る場所 | `okane-data.js` で直すところ |
| --- | --- | --- | --- |
| 毎月（下旬） | 今の物価（全国・総合の前年同月比） | 総務省統計局「消費者物価指数」の最新月 | `CPI_LATEST` |
| 1月下旬 | 物価の年平均 | e-Stat「2025年基準消費者物価指数 長期時系列データ」中分類指数（年平均）のCSV | `CPI` の各配列の最後に1年分を足す |
| 2月ごろ | 家族の支出 | e-Stat「家計調査 長期時系列表 品目分類（年）支出金額（二人以上の世帯）」 | `KAKEI` の各配列に1年分を足す |
| 2〜3月 | 保険料率 | 協会けんぽ（全国平均の料率）、こども家庭庁（子ども・子育て支援金）、厚生労働省（雇用保険料率） | `okane-charts.js` の `calcPay` の料率 |
| 春 | 品物の値段 | e-Stat「小売物価統計調査（動向編）年次」調査品目の月別価格及び年平均価格 | `ITEMS` の `p25`（新しい年の値段）、`CITY`（県庁所在市）、`TREND`（5年ごとの値段の移り変わり） |
| 春 | 初任給・年れいごとの給料 | 厚生労働省「賃金構造基本統計調査 結果の概況」 | `AGEWAGE`、`dev/okane-monosashi.html` の初任給のボタン（`paySeg`） |
| 8〜9月 | 最低賃金 | 厚生労働省「地域別最低賃金の全国一覧」（PDF） | `MINWAGE`（全国平均）、`PREF_WAGE`・`PREF_WAGE_OLD`・`PREF_WAGE_DATE` |
| 12月〜 | 国の予算・税収・国債残高 | 財務省（予算の概要、租税及び印紙収入予算額、普通国債残高の累増） | `BIG`、`TAXREV` |
| 2月ごろ | GDP | 内閣府「国民経済計算」四半期別GDP速報 | `BIG` の `gdp` |
| 毎月 | 人口・ドル円 | 総務省統計局「人口推計」、日本銀行「東京市場 ドル・円 スポット 17時時点 月中平均」 | `POPULATION`、`FX`・`FX_LATEST` |

更新したら、最後に `DATA_FRESH` の「今の数字」と「次の時期」も直します。

## ファイル

- `index.html` … 公開されるページ（`dev/build.sh` で自動で作る）
- `okane.bundle.js` … 公開用に、下のプログラムを1つにまとめたもの（`dev/build.sh` で自動で作る。直接は直さない）
- `guide.html` … 先生・おうちの人への案内（45分の授業プラン5つ・よくある質問）。章の番号を変えたら、ここの番号も直す
- `poster.html` … 教室ポスター（A4・A3印刷用。数字は okane-data.js から自動で入る）
- `dev/okane-monosashi.html` … ページ本体のもと（見た目と文章はここを直す）
- `dev/build.sh` … `bash dev/build.sh` で index.html を作り直す
- `okane-data.js` … 統計データ（年1回ここを更新）
- `okane-app.js` … 換算機・はたらく時間・ランキング・ことば辞典
- `okane-money.js` … 00 お金ってなに？（物々交換の物差し・硬貨のひみつ）
- `okane-charts.js` … タイムマシン・給料と物価・貯金・手取り
- `okane-map.js` … 日本地図
- `okane-kakei.js` … 家族の1万円・今日の発見・スタンプラリー
- `okane-school.js` … 学校にかかるお金
- `okane-big.js` … ニュースの大きな数字を1人あたりに・結果をコピー
- `okane-me.js` … あなたの物差しカード（画像で保存・送る）・自由研究ワークシート
- `okane-tax.js` … 消費税のレシート・ほしい物までの貯金計画
- `okane-fx.js` … 円安・円高（ドル円）・サイトの中をさがす
- `okane-now.js` … ホームの「今の物価」・データの新しさの表
- `okane-diary.js` … わたしのおこづかい帳
- `okane-age.js` … 年れいと給料・読んでいる位置のバー
- `okane-pwa.js`・`sw.js`・`manifest.webmanifest`・`icons/` … ホーム画面に追加して、電波がなくても使えるようにする
- `okane-icons.js` … 章ごとのアイコン
- `okane-ux.js` … もくじ・画面の切りかえ・かんたん表示
- `okane-course.js` … おすすめコース（順番に読む道案内）・文字の大きさ
- `okane-quiz.js` … お金クイズ（5つのモード）
- `okane-tour.js` … はじめての人への使い方ツアー（3ステップ）
- `okane-basket.js` … 買い物かご（同じかごを、10年前と今で何分はたらけば買えるか）
- `okane-flow.js` … お金のめぐり図（家計・会社・国のあいだを、1,100円が回る旅）
- `okane-badges.js` … チャレンジバッジ（「やってみた」ことでもらえる15のバッジ）
- `okane-resume.js` … ホームの「つづきから」（前に読んだ章・進みぐあい・次のおすすめ）
- `okane-market.js` … 値段の決まり方（需要と供給の模型）
- `okane-faq.js` … ものさしくんの なぜなに相談室（よくある疑問に会話で答える）
- `okane-shop.js` … お店やさんゲーム（天気を見て、ジュースの値段と作る数を決める5日間）
- `okane-news.js` … ホームの「あたらしくなったこと」（前に来たときより新しいものに NEW）。機能を足したら、ここにも1行足す
- `okane-history.js` … お金の歴史年表（物々交換からキャッシュレスまで）
- `okane-life.js` … 一生のお金すごろく（学習費と、年れいごとの給料の合計）
- `okane-budget.js` … 国の1年のお金を1万円にちぢめる（歳出・歳入の100マス）。データは okane-data.js の BUDGET
- `okane-meter.js` … 国のお金メーター（予算を1秒あたりに直して数える。画面に見えているときだけ動く）
- `okane-vs.js` … 2つの県をくらべっこ（最低賃金・物価の地域差・県庁所在市の値段）
- `okane-lit.js` … 数字にだまされない！統計の読み方（グラフの目もり・平均と中央値）
- `okane-change.js` … おつりチャレンジ（硬貨とお札でおつりを作る5回のゲーム）
- `okane-cashless.js` … キャッシュレスの広がり（経済産業省の決済比率2010〜2025年。データは okane-data.js の CASHLESS）
- `okane-myinfl.js` … わたしのおこづかい物価（使い道の割合で、自分の10年間の値上がり率を計算）
- `okane-daily.js` … ホームの「今日の1問」（しくみクイズの問題から日にちで1問。れんぞく日数を数える）
- `okane-sugoroku.js` … お金すごろく（20マス・2人で対戦。マスの値段は小売物価統計と最低賃金）
- `okane-talk.js` … 章の終わりの「おうちの人と話そう」（家族と話すきっかけの問いかけ）
- `okane-hub.js` … ホームの「あそんで学ぶ 体験コーナー」（章の中の .bk-head を自動であつめる）
- `okane-speak.js` … 読み上げボタン（この章のポイント・相談室の答え・年表）

外部のサービスとの通信はしません（フォントの読み込みを除く）。設定やスタンプは、使う人のブラウザの中にだけ保存されます。
